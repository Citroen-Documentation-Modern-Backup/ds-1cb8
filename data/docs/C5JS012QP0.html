3. Habillage
3.1. Remplacement connecteur 4 voies par un connecteur 3 voies sur faisceau arrière
Figure : d2aa0avd
Méthode de démontage du connecteur 4 voies :
  • Déclipper le support faisceau  (en "h") ; À l’aide d’un tournevis fin
  • Déclipper le verrouillage faisceau (en "j") ; À l’aide d’un tournevis fin
  • Déposer l’isolant (en "m")
  • Déverrouiller les 4 fils électriques (en "l") ; À l’aide d’un tournevis fin
  • Dégager les 4 fils électriques (en "k") ; À l’aide d’un tournevis fin
Déposer le connecteur 4 voies ("n").
Figure : d2aa0awd
Démonter le connecteur 3 voies ("p") en réalisant les mêmes opérations pour le connecteur 4 voies ("n").
Isoler le fil (10) "62C0" ; À l’aide d’un ruban adhésif isolant.
Connecter les 3 fils électriques sur le connecteur 3 voies ("p").
Insérer le joint (en "q") à l’intérieur du connecteur 3 voies ("p").
Clipper le support faisceau (en "r") sur le connecteur 3 voies ("p").
Figure : d2aa0axd
Insérer l’isolant (en "s") à l’intérieur du connecteur 3 voies ("p").
Clipper le verrouillage faisceau (en "t") sur le connecteur 3 voies ("p").
