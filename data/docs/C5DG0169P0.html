2. Dépose
Mettre le véhicule sur un pont.
2.1. Déflecteurs
Figure : c5jg0v6d
Déclipper les agrafes  (en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer :
  • Les écrous (1)
  • Le déflecteur (2)
2.2. Treuil de roue de secours
Déposer la roue de secours (suivant équipement) (Consulter : La documentation de bord).
Figure : c5dgyfmd
Dégager la fixation  (en "b").
Déposer :
  • Les écrous (3)
  • Le treuil de roue de secours (4)
3. Repose
ATTENTION : Remplacer systématiquement les écrous (3).
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les écrous (3) à 1 m.daN.
Reposer la roue de secours (suivant équipement) (Consulter : La documentation de bord).
Vérifier le fonctionnement des différents équipements.
