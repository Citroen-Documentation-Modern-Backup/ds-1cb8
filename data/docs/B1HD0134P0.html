IMPERATIF : Lors de l’accouplement des outils [0141-T1] / [4192-T], [1604-A] / [4073-T] se protéger à l’aide d’un chiffon, afin d’éviter toute projection de carburant.
Raccorder l’outil [0141-T1] / [4192-T] sur la valve de purge du circuit d’alimentation carburant ( en "a").
Accoupler l’outil [0141-T1] / [4192-T] avec l’outil [1604-A] / [4073-T].
Démarrer le moteur.
Relever les pressions : Pressions de fonctionnement = 5 bars.
Arrêter le moteur.
IMPERATIF : Lors du désaccouplement des outils [0141-T1] / [4192-T], [1604-A] / [4073-T] se protéger à l’aide d’un chiffon, afin d’éviter toute projection de carburant.
ATTENTION : Se munir d’un récipient pour récupérer le carburant.
Déposer les outils [0141-T1] / [4192-T], [1604-A] / [4073-T].
