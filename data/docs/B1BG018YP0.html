2. Précautions avant remontage
ATTENTION : Respecter les consignes suivantes.
Avant remontage :
  • Contrôler puis nettoyer chaque pièce avant repose
  • Nettoyer les plans de joint avec le produit décapant homologué ; Ne pas utiliser d’abrasifs ni d’outils tranchants sur les plans de joint ; Les plans de joint ne doivent comporter ni trace de choc ni rayure
  • Nettoyer les taraudages des vis ainsi que les filetages avant la repose
  • Remplacer systématiquement tous les joints d’étanchéité
3. Remontage
ATTENTION : Respecter les couples de serrage .

Figure : b1bg2ild
ATTENTION : En cas de réutilisation : Respecter le positionnement des demi-coussinets.

  • Les demi-coussinets supérieurs rainurés (1) (Ergots dans les logements)
  • Les demi-flasques supérieurs (2) (rainures de lubrification "a" côté vilebrequin) ; Ergots dans les logements)
Huiler uniformément les demi-coussinets supérieurs (Une goutte d’huile).
3.2. Réglage du jeu latéral de vilebrequin
Figure : b1bg2imd
Huiler uniformément les paliers de vilebrequin (Une goutte d’huile).
Reposer le vilebrequin (4).
Mettre en place :
  • Le support magnétique de comparateur
  • Le comparateur
Appuyer axialement, le vilebrequin dans le carter-cylindres.
Étalonner le comparateur à zéro.
Appuyer axialement, du côté opposé, le vilebrequin dans le carter-cylindres.
Le jeu latéral doit être compris entre 0,07 et 0,32 mm.
ATTENTION : Choisir des demi-flasques supérieurs et inférieurs de même épaisseur pour la même face du vilebrequin.
