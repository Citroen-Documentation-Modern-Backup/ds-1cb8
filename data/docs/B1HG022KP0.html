ATTENTION : Effectuer l’opération moteur froid.
Placer le véhicule sur un pont élévateur à 2 colonnes.
Débrancher la batterie de servitude.
Déposer le pare-chocs avant .

  • Les vis de fixation (1) du refroidisseur d’air de suralimentation
  • Les vis de maintien (2) des brides du radiateur de refroidissement
  • Les brides du radiateur de refroidissement

Déconnecter le connecteur en "a".
Desserrer les colliers (7), (4).
Déposer :
  • Les manchons (8)
  • Les vis (5)
  • Le raccord de sortie d’air (6) du turbocompresseur
  • Les vis (10)
  • Le raccord d’entrée boîtier papillon (3)
Figure : b1hg3ccd
ATTENTION : Veiller à ne pas déformer les tuyaux de réfrigération.

Déposer le refroidisseur d’air de suralimentation (12).
2. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Veiller à ne pas déformer les tuyaux de réfrigération.
ATTENTION : Protéger le radiateur de refroidissement de tout choc.
Repositionner :
  • Le refroidisseur d’air de suralimentation (12)
  • L’ensemble radiateur de refroidissement moteur et condenseur de réfrigération (11)
Reposer :
  • Le raccord d’entrée boîtier papillon (3)
  • Les vis (10)
  • Le raccord de sortie d’air (6) du turbocompresseur
  • Les vis (5)
  • Les manchons (8)
Resserrer les colliers (7), (4)).
Accoupler le tuyau de dégazage (9) du circuit de refroidissement sur le radiateur moteur  (en "b").
Connecter le connecteur en "a".
Reposer :
  • Les brides du radiateur de refroidissement
  • Les vis de maintien (2) des brides du radiateur de refroidissement
  • Les vis de fixation (1) du refroidisseur d’air de suralimentation
  • Le pare-chocs avant
