2. Pose du moteur sur le chevalet
ATTENTION : Le volant moteur ne pouvant s’extraire une fois le moteur en place sur son chevalet, il est impératif de caler la distribution, déposer la vis de poulie de vilebrequin puis déposer le volant moteur avant toute intervention.
Lever le moteur ; À l’aide d’une grue d’atelier.
Figure : b1bpst6d
Poser : Les vis colonnettes [0013] ; Sur moteur (Comme indiqué ci-dessus).
Déposer le goujon démontable de la vis colonnette [0013-2D].
Fixer la vis colonnette [0013-2D] ; À l’aide d’une vis (1).
NOTA : Vis (1) de type M10 longueur 80 mm.
Figure : b1bpstad
Positionner les bras du chevalet [0013], comme indiqué.
Fixer le moteur sur le chevalet ; À l’aide des écrous.
ATTENTION : Vérifier le serrage correct de l’ensemble des fixations avant de détacher la grue d’atelier.
Détacher la grue d’atelier du moteur.
