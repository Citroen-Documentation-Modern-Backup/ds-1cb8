2. Repose
2.1. Motoréducteur volet de mixage (Côté droit )
Figure : c5hg0ewd
Reposer l’engrenage (6) sur le motoréducteur (7) (En butée en "e").
Reposer la biellette (5) sur le motoréducteur (7).
Figure : c5hg0exd
Tourner l’engrenage (4) dans le sens antihoraire jusqu’en butée.
Positionner l’ensemble motoréducteur (7), engrenage (6), biellette (5).
Clipper la biellette (5) sur l’engrenage (4).
Reposer :
  • Les vis (8)
  • La vis (3)
  • Le conduit d’air (2)
  • La vis (1)
  • Le vide-poches
