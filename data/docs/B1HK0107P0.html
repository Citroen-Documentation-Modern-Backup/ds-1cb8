B1HK0107P0Nettoyage : Raccords sur rampe d’injection commune haute pression carburant (HDI)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel :
  • Dégraissant (Type SODIMAC N°35)
  • Pinceau
  • Bac de nettoyage
  • Aspirateur
  • Embout rond
2. Mode opératoire
Figure : b1hj001d
Nettoyage des zones de réparation (en "a") :
  • Verser le produit dégraissant dans le bac de nettoyage
  • Tremper le pinceau dans le produit dégraissant
  • Nettoyer les points "a" avec le produit et aspirer simultanément à l’aide de l’aspirateur
Nettoyer l’aspirateur et l’embout rond après utilisation.
