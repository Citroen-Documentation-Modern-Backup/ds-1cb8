3. Vérifications
ATTENTION : Nettoyer soigneusement chaque pièce à l’aide des produits spécifiques homologués.
3.1. Carter-cylindres
Figure : b1bg2g2d
Le contrôle de la planéité s’effectue à l’aide d’une règle de contrôle et d’un jeu de cales (voir figure ci-dessus).
Déformation maximale admise = 0.042 mm.
Vérifier les points suivants :
  • Vérifier l’absence d’arrachement de métal (Cylindres - Paliers)
  • Mesurer l’usure des différentes pièces (Cylindres - Paliers)
  • Vérifier les différents canaux de lubrification
  • Vérifier l’étanchéité du carter-cylindres (Test d’étanchéité par mise sous pression)
  • Vérifier l’absence de fuites des billes - Obturateurs
  • Vérifier l’absence de fuites des bouchons cuvettes
Remplacer les pièces défectueuses.
3.2. Attelage mobile
Vérifier les points suivants :
  • Vérifier l’absence d’arrachement de métal (Fûts ; Pistons ; Axes de pistons ; Segments ; Bielles ; Demi-coussinets ; Cales latérales ; Vilebrequin )
  • Mesurer l’usure des différentes pièces (Fûts ; Pistons ; Axes de pistons ; Segments ; Bielles ; Demi-coussinets ; Cales latérales ; Vilebrequin )
Remplacer les pièces défectueuses.
3.3. Pompe à huile
Vérifier les points suivants :
  • Vérifier l’absence de particules dans la crépine de pompe à huile
  • Vérifier l’absence de points durs sur la pompe à huile
  • Vérifier l’état des dents sur les pignons de pompe à huile
  • Vérifier l’état de la chaîne de pompe à huile
Remplacer les pièces défectueuses.
3.4. Gicleurs de fond de pistons
Vérifier l’absence de bouchons dans les gicleurs de fonds de pistons.
