2. Opérations préliminaires
Lever et caler le véhicule.
Déposer :
  • La roue arrière
  • Les plaquettes de frein
  • Le disque de frein
  • Le porte-moyeu
3. Dépose
Figure : b3dj02ed
Déposer le circlips (1) ; À l’aide d’une pince.
Figure : b3dj039d
Placer le porte-moyeu (3) dans un étau.
Mettre en place l’outil [06310-T] sur le moyeu (2) ; À l’aide de 2 vis de roue.
Figure : b3dj031d
Positionner : Le grain d’appui [0621-J / 9501-TD2].
Mettre en place les outils [0621-K / 9501-TD5], [0625-C], [0621-C / 9501-TA].
Extraire le moyeu avec la demi-cage intérieure de roulement.
Figure : b3dj02ld
Placer le moyeu (2) dans un étau.
Extraire le pare-poussière (4) ; À l’aide d’un tournevis.
Figure : b3dj032d
Positionner : Le grain d’appui [0621-J / 9501-TD2].
Extraire la cage intérieure de roulement (5) ; À l’aide de l’extracteur FACOM U53.
Reposer la cage intérieure de roulement dans son logement (côté porte-moyeu).
Figure : b3dj02rd
Positionner le tampon de dépose [0625-B].
Extraire le roulement à la presse.
4. Repose
Figure : b3dj02ud
Positionner le roulement de roue sur le porte-moyeu (3).
ATTENTION : Lors de la mise en place du roulement, veiller à ce que la roue magnétique "a" soit du côté du support de capteur de roue (en "b").
Figure : b3dj02xd
Positionner le tampon de montage [0625-D].
Monter à la presse le roulement (6) jusqu’en butée.
Figure : b3dj030d
Positionner :
  • Le tampon de dépose [0625-B]
  • Le tampon de montage [0625-D]
Monter le moyeu (2) à la presse.
5. Opérations complémentaires
Reposer :
  • Le porte-moyeu
  • Le disque de frein
  • Les plaquettes de frein
  • La roue arrière
