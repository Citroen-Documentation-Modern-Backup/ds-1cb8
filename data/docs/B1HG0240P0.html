B1HG0240P0Dépose - repose : Boîtier doseur d’air admission
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Boîtier doseur d’air admission
Débrancher la batterie 12 volts.
Déposer le cache-style moteur .
Figure : b1hg3gtd
ATTENTION : Protéger le radiateur de refroidissement moteur pour éviter d’en détériorer les ailettes.
Déposer le raccord d’air (1).
Déconnecter les connecteurs  (en "a").
Dégrafer le faisceau électrique  (en "b", "c").
Figure : b1hg3gud
Désaccoupler : Le tuyau du circuit de vide (en "d").
Dégrafer et écarter : Le tuyau du circuit de vide (en "e").
Déposer :
  • Les vis (2)
  • Les vis (3)
  • Le boîtier doseur d’air admission (4)
1.2. Le support de boîtier doseur d’air admission  (si nécessaire)
Figure : b1hg3h5d
Dégrafer et écarter la goulotte de passage du faisceau électrique (7).
Déposer :
  • Les fixations (5)
  • Le support de boîtier doseur d’air admission (6)
2. Repose
2.1. Le support de boîtier doseur d’air admission  (si nécessaire)
Reposer :
  • Le support de boîtier doseur d’air admission (6)
  • Les fixations (5)
Agrafer la goulotte de passage du faisceau électrique (7).
2.2. Boîtier doseur d’air admission
Figure : b1hg3h6d
ATTENTION : Vérifier l’état du joint d’étanchéité (8) ; Le remplacer si nécessaire.
Reposer :
  • Le joint d’étanchéité (8) sur le boîtier doseur d’air admission (4)
  • Le boîtier doseur d’air admission (4)
  • Les vis (2)
  • Les vis (3)
Accoupler : Le tuyau du circuit de vide (en "d").
Agrafer : Le tuyau du circuit de vide (en "e").
Agrafer le faisceau électrique  (en "b", "c").
Connecter les connecteurs (en "a").
Reposer le raccord d’air (1).
ATTENTION : Retirer la protection sur le radiateur de refroidissement.
Reposer le cache-style moteur .
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie 12 volts.
