B1HG023UP0Dépose - Repose : Réservoir à carburant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Lève-organe.
Outils Référence Désignation
Figure : e5ab06it
 [0188-T] kit obturateurs
2. Dépose
Mettre le véhicule sur un pont élévateur.
Desserrer le frein de stationnement .
Débrancher la batterie 12 volts.
Vidanger le réservoir à carburant.
Déposer :
  • La roue arrière gauche
  • Le pare-boue arrière gauche
Figure : b1hg3g7d
Déposer la vis de fixation (1) de la goulotte de réservoir à carburant .
Écarter la goulotte de remplissage du passage de roue.
Reposer : Le bouchon du réservoir à carburant .
Déposer la ligne d’échappement .
Figure : b1hg3g8d
Déposer :
  • Les écrans aérauliques (2), (3)
  • Les écrans thermiques (4)
  • Le réservoir d’additif carburant
Figure : b1hg3g9d
Dégrafer : Les durits du circuit de refroidissement (Chaîne de traction hybride) (en "a").
Déposer les écrous  (en "b", "c", "g").
Écarter les durits du circuit de refroidissement (Chaîne de traction hybride).
Dégrafer le câble de frein de stationnement (en "d", "e").
Déconnecter le connecteur (en "f").
Figure : b1hg3gad
Désaccoupler les tuyaux de carburant  (en "h").
Obturer les tuyaux de carburant : À l’aide de l’outil [0188-T].
Figure : b1hg3gbd
Déposer :
  • Les 3 fixations  (en "k")
  • Le support (5)
Soutenir le réservoir à carburant : À l’aide du lève-organe .
Déposer les écrous  (en "j").
Figure : b1hg3gcd
Écarter les pattes  (en "l") ; À l’aide d’un tournevis.
ATTENTION : Opération nécessitant deux opérateurs.
ATTENTION : Guider la tubulure monobloc du réservoir à carburant pour éviter les contraintes sur l’environnement.
Descendre avec précaution le réservoir à carburant.
Déposer le réservoir à carburant .
3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Opération nécessitant deux opérateurs.
ATTENTION : Guider la tubulure monobloc du réservoir à carburant pour éviter les contraintes sur l’environnement.
Déposer : Le bouchon du réservoir à carburant .
Reposer le réservoir à carburant.
Soutenir le réservoir à carburant : À l’aide du lève-organe .
Reposer : Les écrous (en "j").
Enlever le lève-organe.
Reposer :
  • Le support (5)
  • Les 3 fixations  (en "k")
Déposer les bouchons d’étanchéité [0188-T].
Accoupler les tuyaux de carburant  (en "h").
Connecter le connecteur  (en "f").
Agrafer le câble de frein de stationnement  (en "d", "e").
Positionner : Les durits du circuit de refroidissement (Chaîne de traction hybride).
Reposer les écrous  (en "b", "c", "g").
Agrafer : Les durits du circuit de refroidissement (Chaîne de traction hybride) (en "a").
Reposer :
  • Le réservoir d’additif carburant
  • Les écrans thermiques (4)
  • Les écrans aérauliques (2), (3)
  • La ligne d’échappement
  • La vis de fixation (1) (Goulotte de remplissage du réservoir à carburant)
  • Le pare-boue arrière gauche
  • La roue arrière gauche
Remplir le réservoir à carburant.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie 12 volts.
Démarrer le véhicule.
Vérifier l’absence de fuite.
