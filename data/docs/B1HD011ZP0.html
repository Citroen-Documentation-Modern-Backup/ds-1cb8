2. Opérations préliminaires
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI) .
Déposer :
  • Le cache-style moteur
  • La protection du système haute pression carburant
2.1. Circuit basse pression carburant
Contrôler les éléments suivants :
  • La quantité de carburant dans le réservoir : 15 litres minimum
  • La qualité du carburant (en cas de doute sur la qualité du carburant, utiliser un réservoir auxiliaire muni d’un filtre et rempli de carburant dont on connaît la provenance)
  • L’absence de fuite sur le circuit haute pression carburant
  • Le circuit d’alimentation basse pression carburant (filtre colmaté, état des tuyaux, absence de bulles d’air) : Voir la méthode de contrôle du circuit basse pression carburant
2.2. Circuit électrique
Figure : b1hdz94d
Contrôler les éléments pouvant occasionner des dysfonctionnements du système :
  • La charge de la batterie
  • Les codes défauts à l’aide de l’outil de diagnostic
  • L’électrovanne de débit carburant à l’aide du test actionneur disponible dans l’outil de diagnostic (Toucher l’électrovanne en "a" pour sentir vibrer)
  • L’actionneur électrique de chaque injecteur à l’aide du test actionneur disponible dans l’outil de diagnostic (Test auditif des injecteurs en "b", procéder par comparaison)
3. Contrôle : Régulation de pression carburant
Suivre la procédure ci-dessous :
  • Le moteur ne démarre pas : Contrôler la régulation de pression carburant
  • Le moteur démarre : Contrôler les injecteurs diesel
3.1. Contrôle : Régulation de pression carburant
Figure : b1hdz96t
Débrancher les injecteurs  (en "c").
Brancher l’outil de diagnostic sur la prise diagnostic du véhicule ; Sélectionner successivement les menus suivants :
  • Menu Mesures Paramètres
  • Informations circuit carburant
  • Pression carburant commandée - Pression carburant mesurée
Actionner le démarreur durant 5 secondes ; Relever simultanément les valeurs maximales des pressions commandées mesurées sur l’outil diagnostic.
ATTENTION : Les pressions commandées et mesurées doivent être identiques (± 50 bars).
Dans le cas de pressions relevées identiques, le système fournit suffisamment de pression pour démarrer et fonctionner normalement : Certifier les contrôles préliminaires, sinon contacter la plateforme technique.
Dans le cas de pressions relevées différentes, le système ne dispose pas de la pression demandée : Contrôler le retour de fuites des injecteurs diesel.
3.2. Contrôle des injecteurs diesel
Figure : b1hdz9ad
Déconnecter :
  • Les injecteurs diesel  (en "c")
  • Le capteur haute pression carburant  (en "d")
Dégrafer et écarter le faisceau électrique (1).
Désaccoupler les raccords encliquetables de l’injecteur côté distribution vers la pompe haute pression :
  • Tirer la languette de verrouillage vers l’arrière
  • Extraire le raccord encliquetable de retour carburant
ATTENTION : Obturer immédiatement les raccords carburant à l’aide des bouchons [1613-K].
Déposer : Le tuyau de retour carburant (2).
Figure : b1hdz9bd
ATTENTION : Vérifier l’état des joints toriques sur les raccords [1613-P] (remplacer si nécessaire).
Accoupler les 4 raccords [1613-P] sur les injecteurs :
  • Vérifier le déverrouillage de la languette (Tirer vers l’arrière)
  • Insérer le raccord à fond
  • Pousser la languette de verrouillage
  • Tirer modérément sur le raccord pour vérifier la mise en place
Accoupler :
  • Un 5ème raccord [1613-P] préalablement obturé sur la pompe haute pression (en "e")
  • Les bidons outils [1613-F] sur les raccords [1613-P] des injecteurs diesel
Accrocher la barrette porte-bidons [1613-F] au capot moteur.
Connecter :
  • Les injecteurs  (en "c")
  • Le capteur haute pression carburant  (en "d")
ATTENTION : La température d’eau moteur doit être supérieure à 60°C pour le contrôle "moteur tournant". Ne pas actionner les pédales une fois le test lancé.
Mode opératoire :
  • Le moteur démarre : Lancer à l’aide de l’outil de diagnostic le test détection de fuite (1 seul cycle)
  • Le moteur ne démarre pas : Actionner le démarreur pendant 5 secondes
Figure : b1hdz9cd
"A" : Volume recueilli (Moteur non tournant).
"B" : Volume recueilli ( moteur tournant).
ATTENTION : Le volume maximum recueilli ne doit pas excéder 36 ml par bidon (moteur tournant) ou 16 cm de longueur dans chaque tuyau de diamètre intérieur 4 mm (moteur non tournant).
Dans le cas d’un ou plusieurs injecteurs dépassant cette valeur, procéder au remplacement puis recommencer le contrôle.
Dans le cas d’un volume recueilli correct, la pompe haute pression ne fournit pas la pression demandée. Remplacer la pompe haute pression.
ATTENTION : Nettoyer, bouchonner et ranger soigneusement les outils utilisés.
Déposer les outils [1613-F], [1613-P].
ATTENTION : Remplacer systématiquement les joints toriques sur les raccords encliquetables (2) ; Risque de fuites.
Prépositionner le tuyau de retour carburant (2) sur la pompe et les injecteurs en commençant par la pompe.
Accoupler : Le tuyau de retour carburant ((2)) :
  • Vérifier le déverrouillage des languettes (Tirer vers l’arrière)
  • Insérer les raccords à fond en commençant par la pompe puis les injecteurs 1, 2, 3, 4
  • Pousser les languettes de verrouillage
  • Tirer modérément sur les raccords pour vérifier leur mise en place
NOTA : Injecteur N°4 (côté distribution).
Connecter :
  • Les injecteurs diesel  (en "a")
  • Le capteur haute pression carburant  (en "b")
Agrafer - Écarter le faisceau électrique (1).
Reposer :
  • La protection du système haute pression carburant
  • Le cache-style moteur
4. Contrôle final
Effectuer :
  • Un effacement de la mémoire des défauts ; À l’aide de l’outil de diagnostic
  • Un essai routier
  • Une lecture de la mémoire des défauts ; À l’aide de l’outil de diagnostic
