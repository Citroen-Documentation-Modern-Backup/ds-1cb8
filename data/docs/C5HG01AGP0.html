C5HG01AGP0Dépose - repose : Pulseur d’air habitacle
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie .
Déposer la garniture sous la planche de bord  (côté passager).
Figure : c5hg0edd
Déconnecter les connecteurs ( en "a", "b").
Déposer :
  • Les vis (1)
  • Le module de commande pulseur d’air (2)
  • Les vis (4)
  • Le pulseur d’air (3)
2. Repose
Reposer :
  • Le pulseur d’air (3)
  • Les vis (4)
  • Le module de commande pulseur d’air (2)
  • Les vis (1)
Connecter les connecteurs ( en "a", "b").
Reposer la garniture sous planche de bord  (côté passager).
Rebrancher la batterie.
Vérifier le fonctionnement du pulseur d’air.
