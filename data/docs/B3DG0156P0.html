B3DG0156P0Dépose - Repose : Pivot arrière
CHAINE TRACTION HYBRIDE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Remplacement systématique de pièces
Désignation Quantité
Écrou (Biellettes de barre antidévers ) 1
Vis (Bras inférieur de suspension / Pivot) 1
Vis (Bras de suspension / Pivot) 1
Ensemble vis-écrou (Amortisseur / Pivot) 1
Vis (Biellette de réglage parallélisme / Pivot) 1
Vis (Bras supérieur de suspension / Pivot) 1
2. Opérations préliminaires
Desserrer le frein de stationnement .
Lever et caler le véhicule, roues arrière pendantes .
Déposer :
  • La roue arrière
  • Les plaquettes de frein arrière
  • Le disque de frein arrière
  • Le porte-moyeu arrière
3. Dépose
Figure : b3dg0f9d
Déposer l’écrou (1).
Écarter la biellette de barre antidévers.
Déposer la vis (4).
Desserrer les vis (2), (3), (5), (6) sans les déposer.
Placer un lève-organe sous le pivot arrière (Interposer une cale).
Soulever le pivot arrière.
NOTA : Soulever le pivot arrière permet de soulager la contrainte du bras longitudinal .
Déposer :
  • Les vis (3), (2), (5), (6)
  • Le pivot arrière
4. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Train arrière
  • Roue
Reposer :
  • Le pivot arrière
  • Les vis (6), (2), (5), (3) sans les serrer
Figure : b3dg0fad
Placer un lève-organe sous le pivot arrière (Interposer une cale).
Positionner le demi-train arrière à la cote de serrage "A" = 336 mm.
ATTENTION : Respecter l’ordre de serrage.
Serrer les vis (6), (2), (5), (3).
Enlever le lève-organe.
Reposer :
  • La vis (4) sans la serrer
  • La biellette de barre antidévers
  • L’écrou (1)
5. Opérations complémentaires
Reposer :
  • Le porte-moyeu arrière
  • Le disque de frein arrière
  • Les plaquettes de frein arrière
  • La roue arrière
Mettre le véhicule en assiette de serrage .
Serrer la vis (4) .
Contrôler la géométrie des trains roulants (régler si nécessaire).
